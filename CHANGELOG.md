# Changelog

## 0.1.0 (unreleased)

First release. Everything below is in the repository; nothing has been published to PyPI yet.

### Comparison and decision

- Declare the dependence of your data (`iid`, `paired`, `clustered`, `cv_overlap`, `timeseries`);
  the router picks the valid method and prints the plan before running. A combination with no
  valid method is refused rather than silently handed to a naive test.
- Three-way verdict (better / equivalent / inconclusive) against a minimum effect of interest, with
  `n_needed` and a note when more CV repeats cannot help. Holm, Bonferroni and
  Benjamini-Hochberg.
- Every method has an oracle test against a trusted reference (SciPy, statsmodels, mlxtend,
  `arch`, R's `forecast`), or an independent oracle where the paper's numbers could not be
  fetched; each method card says which.

### Methods

- Means: Welch t, paired t, paired bootstrap, sign-flip permutation, cluster-robust (CR1) and
  paired cluster-robust inference.
- A/B testing: two-proportion z, Newcombe and Fisher, CUPED and regression adjustment, the delta
  method for ratios, an automatic sample-ratio check, guardrail and ship decisions, a power and
  sample-size planner (`isbetter plan-size`), and 14-million-row aggregation within 1 GB.
- Cross-validation: Nadeau-Bengio, 5x2cv, McNemar.
- Forecasting: Diebold-Mariano with the HLN correction, stationary and circular block bootstraps
  with Politis-White block lengths, SPA, StepM and the Model Confidence Set (wrapping `arch`).
- Trading: PSR, DSR, MinTRL, a trial registry, PBO-CSCV and a block-bootstrap Sharpe interval.
- LLM evals and small N: Wilson, Jeffreys, Clopper-Pearson and Tango intervals, paired and
  clustered standard errors, and normal-mixture confidence sequences for peeking.

### Reports, viewer and docs

- Markdown and self-contained HTML reports (`report: {format: [markdown, html]}`).
- `isbetter view result.json`: a Streamlit viewer that reads only a saved result (`pip install
  'isbetter[app]'`).
- A calibration table generated by `validation/calibration_table.py`, a failure gallery of six
  "naive method breaks" scripts, five case studies (on synthetic stand-in data) and a mkdocs
  site with a method card for each method.

### Known limits

Stated in the method cards and the README: cluster-robust errors are mildly liberal with few
clusters, Diebold-Mariano with HLN stays slightly liberal at long horizons with few origins, the
block-bootstrap Sharpe interval stays 2 to 4 points short of nominal coverage at T = 500, the DSR
treats trials as independent, and sequential monitoring is routed only for `iid` and `paired`
single-metric comparisons.
