# AB-Testing

A hands-on project for learning how to tell whether A is really better than B.

We work one small step at a time: explore a public A/B dataset, run a test, check that the test
can be trusted, then collect the results into a Power BI dashboard where the conclusions are
yours. See `CLAUDE.md` for how we work and `notes/` for what we found.

The earlier `isbetter` toolkit is kept in `archive/` for reference (git tag `archive/isbetter-v1`).
